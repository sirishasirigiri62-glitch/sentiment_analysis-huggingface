# Sentiment Analysis using Hugging Face

A beginner-friendly NLP project using Hugging Face Transformers and DistilBERT to classify movie reviews as positive or negative.

## Project Overview

This project uses the IMDb movie review dataset to build a sentiment classification model.

The model takes a movie review as input and predicts whether the sentiment is:

- Positive
- Negative

## Technologies Used

- Python
- Hugging Face Transformers
- Hugging Face Datasets
- DistilBERT
- PyTorch
- Google Colab

## Dataset

IMDb movie reviews dataset from Hugging Face.

## Workflow

Text
↓
Tokenization
↓
DistilBERT
↓
Classification
↓
Positive / Negative
